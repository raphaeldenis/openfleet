# The default merge policy is human (design decision D13)

The team pack design specifies `merge.policy = human` by default (D13); the Scape fleet applies it today through mission laws. An agent opens a draft PR and a person marks it ready and merges it. A project opts into merging on green checks through a law or a written mandate. The default stays conservative because merging is outward-facing and hard to undo. Two projects opt in today as Scape practice, not as an OpenFleet feature: OpenFleet through Capitaine's merge law, and openfleet-kb through the rule of 2026-10-28.

Source: already practised by the Scape fleet (notes #102 Standards — Rôles, #46, #84) and the team pack design, section D13 (`openfleet/specs/2026-09-30-team-pack-design.md` under `~/Documents/superpowers/`).
